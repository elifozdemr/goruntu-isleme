# Görüntü İşleme - C

C dili ile PPM (P3) formatındaki resimler üzerinde temel görüntü işleme işlemleri yapan bir proje.

## Özellikler
- Resim dosyasını açma
- Resim bilgilerini okuma
- Piksel bilgilerini okuma
- Gri tonlama
- Negatif
- Parlaklık artırma / azaltma
- Yatay çevirme
- Blur
- Sobel ile kenar tespiti
- Yeni resmi dosyaya kaydetme

## Kullanılan C Konuları

- Struct
- Pointer
- Dinamik bellek
- Dosya işlemleri
- Diziler
- Fonksiyonlar
